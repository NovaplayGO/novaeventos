---

## 🧐 ¿Qué se hace en este repositorio?

Este repositorio alberga un sistema automatizado mediante **GitHub Actions** y scripts de extracción en Python. Su función principal es visitar periódicamente fuentes de programación en vivo, procesar la agenda de partidos y eventos deportivos, y generar archivos JSON estructurados listos para su consumo en las aplicaciones de streaming.
